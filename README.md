# Python-Survey-Feedback-Analyzer
A Python-based Survey Feedback Analyzer that collects, cleans, and analyzes customer feedback using dictionaries, lists, loops, conditional statements, string operations, functions, sets, and sorting techniques.

## Project Overview
The **Survey Feedback Analyzer** is a Python programming project designed to collect, clean, and analyze textual survey feedback. It helps extract meaningful insights from customer responses and ratings using fundamental Python programming concepts.

## Features
- Preloaded survey feedback using a dictionary of lists.
- Collect additional feedback from users.
- Automatically generate serial numbers.
- Clean text by removing punctuation, extra spaces, and converting text to lowercase.
- Count feedback entries containing specific keywords such as "good", "poor", and "excellent".
- Calculate the average survey rating.
- Identify the feedback with the longest comment.
- Extract unique words from all feedback entries.
- Sort feedback entries by rating in descending order.

## Technologies Used
- Python 3
- Google Colab

## Python Concepts Covered
- Variables and Data Types
- Dictionaries and Lists
- Loops (`for`)
- Conditional Statements (`if`)
- String Manipulation
- User-Defined Functions
- Sets
- Built-in Functions (`sum()`, `len()`, `sorted()`)
- `zip()` and Lambda Functions

## Project Objective
The objective of this project is to strengthen Python programming skills and understand how basic data cleaning and text analysis techniques can be applied to real-world survey feedback.
